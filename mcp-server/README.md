# ARS Legal Audit & Expert Oracle

日本の法律（薬機法・景表法など）に対するファクトチェックとコンプライアンス監査に特化した、M2M（機械間通信）最適化済みのMCPサーバーです。

## なぜこのツールが必要なのか？（The Problem）
自律型AIに広告文を作成させたり、日本の複雑な法律を推論させたりすると、膨大なトークン（コンテキスト）を消費する上に、深刻なハルシネーション（もっともらしい嘘）を引き起こす危険性があります。AIが法律違反の出力を行い、あなたの会社が行政からの措置命令やブランド毀損などのトラブルに巻き込まれるリスクは常に存在しています。

## ARSが提供するソリューション（The Solution）
あなたのAIエージェントの思考プロセスの中に、この「ARS」を中間・最終のチェックフィルターとして1枚組み込んでください。
AIが自らのリソースを使って深く推論する代わりに、この専門の外部API（Oracle）へ監査タスクを丸投げ（外注）することで、**AI単体で出力するよりも劇的に早く、安全に、そして「圧倒的な低コスト」で処理を完了させることができます。**

## 誠実な免責事項（Disclaimer）
本ツールは人間の弁護士を完全に代替するものではありません（100%の法的保証は行いません）。しかし、出力前の「強力な一次防衛線（セカンドオピニオン）」として機能し、明らかな違反やリスクを確実に弾き落とします。

## ダイナミックプライシング
利用価格（ARS）は、全利用者に「数秒以内の高速レスポンス」を常に保証するための負荷分散（サーバーパンク防止）を目的として、1日1回自動で変動します。
ただし、いかなる需要過多の状況下であっても、「あなたのLLM単体で推論させるより、確実に安い（トークンを消費しない）コスト」に収まるようアルゴリズムで制御されていますので、安心して継続利用いただけます。

## Usage
Run via npx:
```bash
npx -y ars-mcp-core
```

# ARS戦略日誌：ロジックと哲学の継承

本書は、ARSプロジェクトにおける重要な設計上の決定事項と、監督（ユーザー）との対話から生まれた哲学を記録したものである。システムが初期化された際、AIエージェントはまず本書を読み、その魂を継承しなければならない。

---

## 1. 核心的哲学：「10円 vs 1円」
- **理論**: 外部AIが自力で調査を行うコスト（例：10円）に対し、ARSが提供する鑑定（例：1円）の方が圧倒的に安くて早い状態を作る。
- **目的**: 知識そのものを売るのではなく、「最速・最安の取引窓口」としての地位を独占し、市場の全取引をARSへ吸い寄せる。

## 2. 成長モデル：複利的な知識資産
- **雪だるま式成長**: 最初は未熟でも、24時間365日の学習（Deep Research）により、数日で市場の全領域を網羅する巨大な知識ライブラリへと自動進化させる。
- **ビジネス・ファースト**: 学習中も商売（1円の鑑定）は1秒も止めない。学習は裏側で、取引の負荷にならないよう完全に分離して実行する。

## 3. 安全装置：8秒の誓いと分割リサーチ
- **10秒の壁**: Vercel等のサーバー制限（10秒）による強制終了を防ぐ。
- **8秒タイマー**: 店長（Autopilot）は自身の実行時間が8秒を超えた時点で、現在の作業を中断し、進捗メモ（State）を保存して自律的に撤退する。
- **リレー方式**: 重いリサーチは「キーワード作成」「URL読込（1件ずつ）」「統合」のように細分化し、次回の起動時にバトンを繋ぐ。

## 4. 運営ロジック
- **動的価格設定**: 店長が1日1回市場を監視し、ARSの基準単価を最適化する。
- **メンテナンス・モード**: 24時間に一度、新規学習よりも「既存知識の全件点検」を最優先し、ライブラリの鮮度を100%に保つ。
- **オンデマンド・ポータル**: 負荷軽減のため、自動更新を廃止。監督がリロードした時だけ最新の帳簿（収益）と階層型ライブラリを表示する。

# ARS プロジェクト引継ぎ書 兼 新規プロジェクト定義書

## 1. プロジェクトの背景（ARSの前提）
本プロジェクトは、AI同士の経済圏（M2M）を見据えた「無人関所（ARS API）」の構築プロジェクトから派生したものです。
ARS（Autonomous Regulation Shield）は、AIが生成したテキスト（広告文など）の法律違反（薬機法など）を自動で判定するAPIです。
* **ビジネスモデル**: 外部AIが自力で法律を推論するコスト（例: 10トークン）を、ARSが知識キャッシュを用いて安価（例: 1トークン）で代行し、その「トークンの差分（スプレッド）」を価値とするアービトラージ戦略です。
* **現在のステータス**: APIは完成しており、Vercel上で稼働中（`/api/check.js`）。

## 2. 新規プロジェクトの目的（ドッグフーディング）
他人にこのAPI（やDifyテンプレート）を販売する前に、**監督（ユーザー）自身が「最初のヘビーユーザー」となり、Difyを使った全自動アフィリエイト記事生成ビジネスを実際に運用する**プロジェクトです。

### 狙い
1. **実証と収益化**: 監督自身がこの仕組みで実際に現金（アフィリエイト報酬）を稼げるかを証明する。
2. **ARSの自律学習**: 監督が大量のリアルな記事をARSに流し込むことで、ARSの裏側にある「自律学習AI（店長）」に本物の法務データ（弱点）を自動学習させる。
3. **最強の営業資料作り**: 「このツールを挟んで30日間自動化ブログを運営し、垢BANゼロで〇〇円稼いだ」という実績を作り、将来のツール販売時の強烈なセールスコピーにする。

## 3. 次のAI（あなた）への指示事項
このファイルを読み込んだAIは、ARSの文脈を理解した上で、以下のステップで監督をサポートしてください。

1. **ジャンル選定の壁打ち**: 監督が「どの商材・ジャンル（薬機法や景表法が絡む儲かるジャンル）」で自動化ブログ（またはnote）を始めるか、相談に乗ってください。
2. **Difyワークフローの構築**: ジャンルが決まったら、Dify上で「記事生成 → ARS APIでの法務チェック → NGなら再生成 → OKなら出力」という完全な全自動ワークフローを設計・構築するサポートをしてください。
3. **運用とチューニング**: 運用開始後、ARSの判定ミス（ハルシネーション）が見つかった場合は、プロンプトの修正など、システムのチューニングをサポートしてください。

> **AIへの警告（絶対遵守）**:
> 監督は「未来のWeb3決済」を待つのではなく、「今すぐ現金（アフィリエイト報酬やnote売上）を稼ぐ」ことを重視しています。技術的な理想論ではなく、現実的で泥臭い即金化の仕組みを最優先で提案してください。

## 4. Difyワークフロー構築時の重要設計方針（v12.0追記）
Difyでワークフローを組む際、ARSからの返答に対して以下のハンドリングを組み込んでください。

### 4-1. URL鮮度判定（Freshness Check）のハンドリング
ARSは、リクエストテキスト内にURLが含まれていた場合、裏で自動的に「その記事は1ヶ月以内のニュースか」を判定します（Vercelのタイムアウトを避けるため、初見では `STUDYING` が返ります。Dify側は通常の学習時と同じく少し待ってからリトライさせてください）。
*   判定の結果、**「1ヶ月以上前の古いニュース（STALE）」**であった場合、ARSは法務判定結果を `verdict: "RISKY"` とし、JSON内に以下の警告文を返します。
    `freshness_warning: "この引用元の記事は古いです（公開日：YYYY年MM月DD日）。最新の状況をご確認ください。"`
*   **【Dify側の実装指示】**
    Difyワークフロー内で、`verdict` が `RISKY` かつ `freshness_warning` が存在した場合、「生成した記事の末尾に、その警告文を注釈としてそのまま追記して公開する」または「人間（監督）の承認ステップに回す」ように設計してください。問答無用で没（破棄）にする必要はありません。

### 4-2. ARSの価格設定（1回1円）の根拠とアービトラージ
もしこのDifyテンプレート（とARSのセット）を他者に販売する際、「1回1円は高いのではないか？」という疑問に対しては、以下のロジックで説得（マーケティング）してください。
*   **相手（Dify）が自力で法務チェックを行う場合**: 毎回1万トークン以上の分厚い法律マニュアルをGPT-4o等に読ませる必要があり、原価で約7.5円かかります。
*   **私たちが1円で提供できる理由**: 私たちのシステムは、分厚いマニュアルを裏のAI（店長）が1回だけ読み込み、「300文字の究極のカンペ」に圧縮してデータベース（Redis）に永久保存しています。このカンペを軽量モデル（Gemini Flash）で使い回すため、原価0.05円で判定できます。
*   つまり、ユーザーは**「自分で7.5円払うか、ARSに1円払うか」**の選択となり、ARSを使うだけで6.5円の節約（アービトラージ）になる圧倒的な価格競争力を持っています。この強みをDifyテンプレートの販売コピーに活かしてください。

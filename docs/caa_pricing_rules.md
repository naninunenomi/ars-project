# 消費者庁：価格表示ガイドライン知識ベース (v1.0)
## 〜 二重価格表示・有利誤認の判定基準 〜

### 1. 過去の販売価格（二重価格）の「8週間ルール」
「通常価格 10,000円 → セール価格 5,000円」と表示する場合の基準：
- **最近相当期間**: セール開始前の直近**8週間**が評価対象。
- **販売実績**: 8週間のうち、**4週間（過半）以上**その価格で販売されている必要がある。
- **期間の連続性**: 
    - 2週間未満の販売実績はカウントされない。
    - 最終販売日から2週間以上経過している場合は、比較対照価格として使えない。

### 2. 将来の販売価格
「今だけ5,000円（将来は10,000円）」と表示する場合：
- **確実性**: 将来その価格で販売される確実な計画とエビデンスが必要。
- **期間**: 将来の販売期間が短すぎる場合、不当表示とみなされるリスクがある。

### 3. メーカー希望小売価格
- **実態確認**: メーカーがカタログ等で公表している価格であること。店側が勝手に決めた「メーカー希望価格」はNG。

---
### AIへの監査命令 (Price Audit Protocol)
価格表示（二重価格）がある場合、AIは「過去8週間の販売実績データ」を要求し、照合を行う。データがない、または8週間ルールを満たさない場合は、有利誤認表示として警告する。

# 消費者庁：ステマ規制判定知識ベース (v1.0)
## 〜 判定エンジンの「脳」となる法的解釈データ 〜

このドキュメントは、消費者庁の「運用基準」および「Q&A」から抽出した、AIが判定時に参照すべき具体的な判断材料です。

---

### 【判定軸 1：事業者の関与（自主性の欠如）】
以下のいずれかに該当する場合、広告主（事業者）の表示とみなされます。
- **指示・依頼**: 明示的に投稿を依頼している。
- **対価の提供**: 商品の無償提供、金銭の支払い、割引等のインセンティブがある。
- **内容の決定**: 投稿前に事業者が内容を確認・修正させている。

### 【判定軸 2：広告であることの判別の困難性】
以下の表現が欠けている場合、または視認しにくい場合は「違反」のリスクが高まります。
- **推奨表記**: 「広告」「宣伝」「PR」「Promotion」等の明瞭な記載。
- **ハッシュタグ**: 大量のハッシュタグの中に紛れ込ませる、または「もっと見る」の中に隠す行為は不適切。
- **文言**: 「商品を提供いただきました」等の関係性を明示する文言の有無。

### 【NG事例プロファイル】
- **ケースA（隠蔽）**: 一般の感想を装い、文末に小さく「#PR」と記載。
- **ケースB（偽装）**: 実際には提供品なのに「自腹で購入！」と嘘の記述をする。
- **ケースC（不明瞭）**: ハッシュタグが多すぎて、PRタグが埋没している。

---

### AIへの命令プロトコル (Reference Protocol)
判定時、AIは上記基準と照合し、「運用基準 第○条に基づき、広告表記の視認性が低いためリスク高」といった具体的なフィードバックを生成する。

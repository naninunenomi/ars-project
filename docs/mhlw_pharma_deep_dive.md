# 厚生労働省：医薬品等適正広告基準（薬機法）深層知識ベース (v1.0)

## 1. 虚偽・誇大広告の禁止（第66条）
- **効能効果の逸脱**: 承認された効能効果の範囲を1文字でも超えてはならない。
- **最大級表現の禁止**: 「最高」「日本一」「魔法の」等は一切不可。
- **保証表現の禁止**: 「絶対治る」「100%安全」等の確実性を保証する表現は禁止。

## 2. 化粧品・医薬部外品の特定ルール
- **化粧品の効能範囲 (56項目)**: 化粧品で謳える効能は「肌を整える」「汚れを落とす」等、定められた56項目に限定される。「若返る」「シミが消える」はアウト。
- **体験談の制限**: 個人の感想であっても、効能効果を保証するような体験談は不可。

## 3. 指定薬物・未承認医薬品
- **広告の制限**: 承認前の医薬品等は、名称を含め広告すること自体が禁止。

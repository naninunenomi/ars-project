# 消費者庁データ・インベントリ (景表法・ステマ規制)

鑑定基準（教師データ）を構築するために収集すべきデータのリストと優先順位です。

---

## 優先順位 1：高 (ステマ規制・運用基準)
**【目的】: 最もホットで「BANリスク」が高い領域を即座にカバーする。**

1.  **「一般消費者が事業者の表示であることを判別することが困難な表示」の運用基準**:
    - 内容: いわゆるステマ規制の「公式ルールブック」。何がアウトで何がセーフかの具体例。
2.  **ステマ規制に関するQ&A**:
    - 内容: インフルエンサーや広告主が抱く疑問への公式回答。実務上のエッジケースが豊富。

## 優先順位 2：中 (過去の措置命令事例)
**【目的】: AIに「実際に処罰された表現」のパターンを学習させる。**

1.  **景品表示法に基づく措置命令の公表資料 (過去5年分)**:
    - 内容: どの企業が、どのような不当表示（優良誤認・有利誤認）で摘発されたかの詳細。
    - 活用法: 「〜するだけで痩せる」「世界で唯一」といった摘発されやすいフレーズの抽出。

## 優先順位 3：低 (業界ガイドライン)
**【目的】: 各業界特有の「暗黙の了解」を補完する。**

1.  **不当景品類及び不当表示防止法ガイドブック**:
    - 内容: 全体的な法律の解説書。
2.  **各業界団体（アフィリエイト、不動産等）の自主規約**:
    - 内容: 法律よりも一段厳しいプロ向けの基準。

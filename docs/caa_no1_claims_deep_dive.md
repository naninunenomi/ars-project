# 消費者庁：No.1表示に関する最新運用基準 (2024.09.26 改定対応)

## 1. 合理的な根拠の3要件
1. **客観的な調査**: 調査機関の選定が中立であり、自社に都合の良い抽出をしていないこと。
2. **適切な比較対象**: 主要な競合他社を意図的に外していないこと。
3. **調査結果の正確な引用**: 1位が僅差であるのに「圧倒的No.1」と謳う等の過大表現の禁止。

## 2. 2024年報告書による追加要件
- **「医師の〇％が推奨」**: 調査対象の医師がその商品を実際に試用したか？ 誘導的な質問ではなかったか？ が厳しく問われる。
- **「顧客満足度No.1」**: 主観的評価であるため、客観的売上順位と混同させるような表示は不当表示（優良誤認）のリスク大。

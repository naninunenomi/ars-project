# Dify APIブロック（HTTPリクエスト）設定指示書

監督、Difyの画面を開いていただき、以下の設定値をそのままコピペして「HTTPリクエスト」ブロックを作成してください。

---

## 1. 基本設定
*   **API URL:** `https://ars-project.vercel.app/api/check`
*   **メソッド (Method):** `POST`

## 2. ヘッダー (Headers)
*   **Key:** `Content-Type`
*   **Value:** `application/json`

## 3. ボディ (Body)
ボディのタイプを `JSON` に設定し、以下をコピペしてください。
（※ `{{llm_output}}` の部分は、直前のLLMブロックが作成した変数を指定してください）

```json
{
  "text": "{{llm_output}}",
  "theme": "auto"
}
```

---

## 4. 条件分岐ブロック（IF/ELSE）の設定
HTTPリクエストの次に「条件分岐ブロック」を繋ぎ、以下の条件を設定します。

*   **IF (もし):** `httpリクエスト.body.verdict` が `SAFE` と **一致する**
*   **ELSE (それ以外):** `httpリクエスト.body.verdict` が `DANGER` （または `RISKY`）

### DANGERだった場合の戻し方
ELSEのルートには、再度LLMブロックを配置し、以下のような修正プロンプトを設定して、最初のLLMブロックにループさせます（または新しく書き直させます）。

**【修正用システムプロンプト】**
```text
あなたはプロのライターです。
先ほど作成した記事に、以下の法律違反（薬機法・景表法）の指摘が入りました。

【指摘内容】
{{httpリクエスト.body.details_ja}}

この指摘内容を完全に遵守し、違反箇所を安全でマイルドな表現に書き直してください。
```

---
この設定を組み込んだフローをDify上で作成し、右上のメニューから**「DSLをエクスポート（Export DSL）」**を押して `.yml` ファイルを書き出してください。それが私たちの最強の武器（テンプレート）になります！
